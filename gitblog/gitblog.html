Who am I ?

배우고 기록하며 동료와 함께 성장하는 개발자 Supianna입니다.

소개 (About)

안녕하세요! 복잡한 요구사항을 명확하고 작은 단위로 분해하여 정갈한 코드를 짓는 것을 좋아하는 개발자 Supianna(수피아나)입니다.

코드의 겉모습뿐만 아니라 내부 구조가 얼마나 유지보수하기 편하고 읽기 쉬운지를 깊이 고민하며, 새로운 기술의 본질을 파고드는 탐구를 즐깁니다.

개발 철학 (Philosophy)

  • 단일 책임 원칙 (SRP): 하나의 함수와 모듈이 단 하나의 명확한 책임만을 갖도록 정돈합니다.
  • 기록을 통한 체계화: 마주한 문제와 해결 과정을 글로 정리하여 지식의 깊이를 더합니다.
  • 신뢰할 수 있는 협업: 단일 책임 커밋과 명확한 소통으로 함께 일하기 편한 동료가 됩니다.

기술 스택 (Tech Stack)

HTML5 / Semantic Web CSS3 / Responsive Design JavaScript (ES6+) Canvas API Clean Code & SRP Git & Atomic Commits GitHub Pages
